Built with free software

The browser version of Riah Church Translate runs inside this browser. The models download once from Hugging Face into the browser's own storage; nothing said in church is sent anywhere. It stands on these free projects, used under their licenses.

Hearing the speaker

  • Whisper speech models (base.en and small.en) by OpenAI, MIT License, in the ONNX versions published by onnx-community on Hugging Face
  • Silero VAD (finds the pauses), MIT License
  • The live "two passes agree" method is adapted from whisper_streaming by ÚFAL, Charles University, MIT License

Translating

  • NLLB-200 (distilled, 600M) translation model by Meta AI, in the ONNX version published by Xenova on Hugging Face. Creative Commons Attribution-NonCommercial 4.0 (creativecommons.org/licenses/by-nc/4.0): free for churches and other non-commercial use, not for sale.

Running the models in the browser

  • Transformers.js by Hugging Face, Apache License 2.0
  • ONNX Runtime Web by Microsoft, MIT License

Bible names

  • The list of Bible names, books and words was built by lining up these Bibles. Only the word list ships with the page, never the Bible text.
  • World English Bible, Berean Standard Bible and King James Version (English), public domain
  • Thai Freedom Bible (draft), public domain
  • Chinese Union Version, Simplified and Traditional, public domain
  • Thai King James Version, © 2003 Philip Pope, Creative Commons BY-NC-ND 4.0: used only to double-check spellings, no text taken

Type
