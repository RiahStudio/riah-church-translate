Built with free software

Riah Church Translate runs on this computer. It stands on these free projects, used under their licenses.

Hearing the speaker

  • Whisper speech models by OpenAI, MIT License
  • faster-whisper by SYSTRAN, MIT License
  • CTranslate2 by OpenNMT, MIT License
  • Silero VAD (finds the pauses), MIT License
  • The live "two passes agree" method is adapted from whisper_streaming by ÚFAL, Charles University, MIT License

Translating

  • NLLB-200 translation model by Meta AI, converted by OpenNMT. Creative Commons Attribution-NonCommercial 4.0 (creativecommons.org/licenses/by-nc/4.0): free for churches and other non-commercial use, not for sale.

Bible names and verses

  • The list of Bible names, books and words was built by lining up these Bibles. The verses shown on screen come from the public-domain Bibles below, unchanged.
  • World English Bible, Berean Standard Bible and King James Version (English), public domain
  • Thai Freedom Bible (draft), public domain
  • Chinese Union Version, Simplified and Traditional, public domain
  • Thai King James Version, © 2003 Philip Pope, Creative Commons BY-NC-ND 4.0: used only to double-check spellings, no text taken

Sound, screens and the app

  • PyAV, BSD License, with FFmpeg, LGPL 2.1 or later
  • python-sounddevice, MIT License, with PortAudio, MIT License
  • NumPy, BSD License · ONNX Runtime by Microsoft, MIT License
  • Hugging Face tokenizers and huggingface_hub, Apache License 2.0
  • pywebview, BSD License · Python, PSF License
  • pypdf, BSD License (reads sermon notes saved as PDF)
  • FFmpeg comes inside PyAV as separate libraries, unchanged; its source is at ffmpeg.org.
  • Full license texts for every library inside the app.
